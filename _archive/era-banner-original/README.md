# The original era banner

The classic site's banner as it was before the tuning dial: the rainbow stripes,
"Boot this portfolio on a computer from 1983" ("Step into 2000" on a phone), the
little machines with faces, the "Step in" button and the "Time Travel" chip.

To put it back, replace these with the files here:

- `banner.html`: in `index.html`, everything from the `<!-- The way into the eras` comment through the `eraMini` link.
- `banner.css`: in `style.css`, everything from `/* The way into the eras:` to the end of the file.
- `banner.js`: in `script.js`, everything from the `The way into the eras` comment block to the end of the file.

GitHub Pages doesn't publish folders starting with an underscore, so this stays private to the repo.
